01. Developer & contact information

Bloede Feainne Games is the developer of Merge Planets: Make a Galaxy!, an Android casual physics puzzle game made with Unity. This notice concerns information processed in connection with the game and communications with the studio.

For game support or privacy requests, email bloedefeainne.games@outlook.com.

02. What information is processed

In the game code reviewed, gameplay runs on the device. The code processes the current score and saves the best score and selected preferences. It reads the device’s current interface-language setting to choose an initial game language when no saved choice is available.

No account registration, sign-in, authentication service, cloud-save system, custom telemetry uploader, or calls to device-identifier APIs were found in the reviewed game code. This is a source-audit finding, not a guarantee about all Unity runtime behavior in a future release.

If you email the studio, your message is sent off your device. The studio receives your email address, any sender name, the message, attachments you choose to include, and normal email metadata. This information is used to handle your enquiry, support issue, or privacy request.

03. Local gameplay storage

The reviewed code uses Unity’s PlayerPrefs preference storage for:

  • The best score achieved on the device.
  • Whether sound is enabled.
  • Whether vibration is enabled.
  • The selected game language, when you make a selection.

The current game score is maintained in memory during play. The reviewed code does not implement uploading these saved preferences or synchronizing them with a studio server. Localization and Addressables assets are configured to load from the game’s local content, rather than a configured remote content service.

Android backup is separate from the game’s save code. The inspected APK does not explicitly disable Android backup or define backup exclusions. Depending on Android, device, account, and backup settings, the operating system may back up or transfer app data. This means locally saved preferences must not be described as guaranteed never to leave the device. See Android’s backup documentation.

[VERIFY: RELEASE BACKUP SETTINGS]Confirm backup and device-transfer rules in the final merged Android manifest, and whether the release’s saved preferences are included. Do not promise that uninstalling removes backups.

04. Unity & third-party services

The available project uses Unity 6000.3.14f1. Its resolved packages include Unity Localization, Addressables, and RTLTMPro for game assets and localized text. These package names do not establish that information is sent to their providers.

In the reviewed configuration, Unity Analytics, Unity Ads, Unity Purchasing, Cloud Diagnostics reporting, and Performance Reporting are disabled, and no Unity Cloud project link is configured. No Firebase, AdMob, Unity Gaming Services initialization, authentication, or purchasing SDK integration was found in the reviewed dependencies and game code.

Engine diagnostics require a separate check. The project contains an enabled engine-diagnostics setting, separate from the disabled Analytics setting. Unity’s build-profile documentation states that diagnostic collection is disabled for projects not connected to Unity Cloud. The missing cloud link is relevant evidence, but the final release configuration and actual network behavior have not been confirmed.

The verified game-side purposes are running gameplay, displaying scores, remembering your best score, and applying your language, audio, and vibration preferences. Support correspondence is used to respond to the issue or request you send to the studio.

No custom code for sending gameplay preferences to the studio or sharing them with an advertising, analytics, account, or cloud-save provider was found. Android backup, voluntary email, and any release-specific Unity processing are separate matters described above.

06. Retention & deletion

The reviewed save code does not set an expiry for the best score or preferences. They remain in the app’s preference storage until replaced or removed. Android’s app settings normally offer a way to clear the app’s storage; doing so resets these local values. The exact option name depends on the device.

Clearing local storage or uninstalling the game does not establish deletion of operating-system backups, previously sent email, or any information a service might hold. Manage Android backup copies through the relevant device or account controls. The reviewed game does not implement a studio account or a remote save-deletion service.

For correspondence held by the studio, send a deletion enquiry to bloedefeainne.games@outlook.com.
